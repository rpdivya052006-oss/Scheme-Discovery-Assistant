# 🇮🇳 Scheme Discovery Assistant

## 📌 About the Project

**Scheme Discovery Assistant** is a mobile-first web application designed to help Indian citizens discover government schemes that they may be eligible for.

The application collects basic information such as age, gender, occupation, family income, state, category, and specific needs. Based on the user's responses, it provides a list of potentially relevant government schemes along with a match percentage, benefits, eligibility information, and required documents.

## 🎯 Objectives

- Help citizens discover relevant government schemes easily.
- Provide a simple and user-friendly interface.
- Reduce the difficulty of searching through multiple government schemes.
- Provide personalized scheme recommendations based on user-provided information.
- Support both English and Tamil languages.

## ✨ Features

- 🇮🇳 Citizen-friendly interface
- 🌐 English / Tamil language toggle
- 📝 Step-by-step eligibility questionnaire
- 📊 Progress bar during the questionnaire
- 🎯 Scheme matching based on user information
- 📈 Match percentage for each scheme
- ✅ "Why this matched you" section
- 🔎 Scheme filtering
- 📋 Detailed eligibility information
- 📄 Required document checklist
- 📥 Downloadable checklist
- 🌐 Apply button for accessing government information

## 🔄 How It Works

1. The user opens the Scheme Discovery Assistant.
2. The user selects a preferred language.
3. The user clicks **"Find my schemes"**.
4. The application asks questions one by one.
5. The user enters their personal and eligibility information.
6. The system compares the information with available scheme criteria.
7. Relevant schemes are displayed with match percentages.
8. The user can view scheme details and required documents.
9. The user can download the document checklist.
10. The user can proceed to the relevant government information/application portal.
